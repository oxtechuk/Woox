إضافة الربط السحابي الرسمي بين متجر ووكومرس ومنصة Wox WhatsApp لإرسال إشعارات الطلبات اللحظية، رموز التحقق OTP، واستعادة السلات المتروكة.

== Description ==
تتيح لك إضافة **Wox WhatsApp for WooCommerce** ربط متجرك الإلكتروني بمنصة Wox السحابية لإرسال إشعارات فورية عبر تطبيق الواتساب للعملاء ومديري المتجر:
- إشعار فوري عند إنشاء طلب جديد أو تغيير حالة الطلب (قيد المراجعة، جاري التجهيز، تم الشحن، تم الإلغاء، مكتمل).
- إرسال رسائل التحقق (OTP) السريعة عند تسجيل الدخول أو إتمام الدفع.
- إرسال تذكيرات مخصصة لاستعادة السلات المتروكة مع كوبونات خصم تشجيعية.
- إرسال لا تزامني (Asynchronous) لضمان عدم تأخير المتجر أو إبطاء عملية الدفع.
- قوالب رسائل قابلة للتخصيص بالكامل تدعم الرموز التعبيرية والمتغيرات الديناميكية مثل: `{customer_name}`, `{order_id}`, `{status}`, `{total}`, `{currency}`, `{tracking_url}`.

== Installation ==
1. قم برفع مجلد `wox-whatsapp` إلى مسار `/wp-content/plugins/` أو ارفع الملف المضغوط `wox-whatsapp.zip` عبر لوحة تحكم ووردبريس (إضافات -> أضف جديد -> رفع إضافة).
2. قم بتفعيل الإضافة من قائمة الإضافات في ووردبريس.
3. اذهب إلى لوحة التحكم -> **Wox WhatsApp**.
4. أدخل رابط المنصة (API URL)، اسم الـ Instance، والـ API Token، ثم اضغط على زر **فحص الاتصال**.
5. احفظ الإعدادات وسيبدأ الإرسال التلقائي للطلبات.
